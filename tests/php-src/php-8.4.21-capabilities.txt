# PHPT gate capabilities for php-src 8.4.21.
#
# These are reported as explicit unsupported/skip statuses. They are not
# removed from the overall case count or silently converted into passes.

runtime-cli:INI
  RPHP has no per-process INI contract yet. Tests with a non-empty INI section
  are classified unsupported/runtime-cli-ini.

runtime-cli:ARGS
  RPHP does not yet publish script arguments. No selected 8.4.21 case currently
  uses ARGS, but the runner keeps the classification explicit.

runtime-extension:EXTENSIONS
  RPHP does not advertise PHP extension modules. A declared extension that is
  unavailable is a normal PHPT skip and remains visible in the manifest.

runner:PHPDBG,POST_RAW,GET,EXPECTHEADERS
  These request a debugger or CGI/header transport rather than the selected CLI
  runtime. They are classified unsupported/section until those execution modes
  have their own compatibility gates.
